The GRFT+ event workflow, end to end.

Start in the Event Tracker — creating an event spins up an Asset Manager page you email to the client, and a Call Sheet for the crew. Everything's interactive; use your browser's Back button to return to this menu.

01 · Internal · start here Event Tracker

The hub. Create an event and it generates the client’s Asset Manager page and the crew’s Call Sheet. Records hold display type, cases & equipment, the setup diagram, inventory, notes and team roles.

Open module → 02 · Client self-serve Asset Manager

Auto-created with each event and emailed to the client. They build their wall — logos, full palette, spray-can label with 360° inspect, multi-logo overlay — on a timeline with drop-dead dates. Every step auto-saves.

Open module → 03 · Technician · mobile Call Sheet

Opened by the crew on their phone via an open link. Schedule, client contact, license key, notes, the setup diagram, the case packing checklist, and a real PDF download.

Open module → + · Tool Setup Diagram

Generate the wall elevation from dimensions, ratio and mount height — auto-places lighthouses, home tracker and transmitters. Drag to adjust, toggle units, export PDF / PNG.
