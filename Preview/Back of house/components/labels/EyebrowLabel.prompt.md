```jsx
<EyebrowLabel>The programming · Air giants</EyebrowLabel>
<EyebrowLabel onDark={false} lead="none">Featured</EyebrowLabel>
```

Yellow on dark, mono-grey on light. Dot-separate multiple segments. Labels only — never set body or headlines in mono.
